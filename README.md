# Facebook Redesign UI in Flutter 📱🔥

A modern **Facebook-inspired social media UI** built with Flutter. This project focuses on creating a clean, polished, and responsive social media experience with a redesigned interface.

## 📂 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YaqoobDeveloper/Facebook-Redesign-UI-in-Flutter.git
```

### 2. Navigate to the project

```bash
cd Facebook-Redesign-UI-in-Flutter
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
